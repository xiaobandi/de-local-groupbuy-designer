# 03 · 场景与价值

## 谁在用

所有做团购的到店门店

## 三个典型场景

### 场景 A：竞品团购监控
- **触发**：定时（每周）
- **之前**：人工从头做一遍，每次口径不一、结果不可比
- **之后**：抓取商圈同品类 TOP 店团购结构与价格 → 对比表
- **收益**：替代人工逛街调研，月省 8 小时

### 场景 B：套餐结构设计
- **触发**：人工（发起策划）
- **之后**：引流款/主力款/利润款三级组合建议
- **收益**：一次策划服务市价 200–500 元（据 R4 调研）

### 场景 C：扣点毛利测算
- **触发**：随 W2 联动
- **之后**：叠加平台扣点+达人佣金（综合费率 5–7%+，据 R4 调研）→ 毛利红线校验
- **收益**：避免单笔亏损套餐，止损价值直接

## 价值构成

| 维度 | 说明 |
|---|---|
| 省时间 | 一次避开亏损套餐即可回本；按次收费模式契合"单次 ≤¥300"小额验证硬边界 |
| 提一致性 | 同一能力固化成技能，口径不再因人而异 |
| 降风险 | 业务红线写死在提示词里，越界即停 |
| 可审计 | 每个数字可回指输入，产出可追溯 |

## 与人工的边界

本员工**不替代决策**。它负责把重复劳动做成清单与初稿，
把决策点（要不要发、要不要改价、要不要道歉）留给人。
