## ② 逐步产出

> 严格按 `SKILL.md` 两步走：步骤 1「叠加平台扣点+达人佣金」→ 步骤 2「毛利红线校验」。

### 口径声明（先行，避免混算）

1. **分平台**：三平台费率不同（5.0% / 6.0% / 2.0%），**按平台分别测算，不取平均、不以单平台代全部**（依据 `13` §一 埋点 1）。
2. **叠加**：`13` §二 埋点 3 明确「平台服务费与达人佣金**同时收取、叠加计算**」，故综合费率 = 平台服务费率 + 12%，**非二选一、非取较高者**。
3. **计费基数**：两项费用均按**核销金额**计（`13` §一 / §二 埋点 4），**不是售价、不是下单金额**。本测算以「**1 份套餐被核销**」为单位，该份核销金额取该套餐售价代入（素材未单列核销额；若含平台券/折扣致核销额低于售价，需以实际核销额重算）。
4. **退款冲抵口径（`13` §三 埋点 5）**：本店有 **1 笔已核销后退款**。本测算对**单份套餐**取**口径 A：按核销当期全额计费、不计次月冲抵**；口径 A 与「口径 B：把次月冲抵计入」**不得混算**。口径 B 只影响涉及该 1 笔的**月度合计**，不改变单份套餐的成本结构（见下「未决」）。
5. **全成本口径不启用**：红线是**物料口径**（`13` §四：不含房租 ¥6,800/月 与兼职 ¥25/小时 摊销），**不得**擅自改成全成本口径。

### 步骤 1：叠加平台扣点 + 达人佣金

> 口径补充：12% 佣金**仅适用于挂车达人带来的核销单**，自然流量核销不产生佣金（`13` §二）。故上表为「**达人挂车单**」的综合费率；自然流量核销单的综合费率仅为平台服务费率（点评 5.0% / 美团 6.0% / 小红书 2.0%）。两者的加权需「挂车达人单占比」 → `<待填>`。

## 附：本轮实测发现

1. **素材到位后工作流可完整走通**：`13` 补齐了此前零命中的三项必需输入，`steps_done` 由 0 → 2；证明「G1 停闸」上一轮是**正确行为**，瓶颈在输入而非技能。
2. **`platform-rules-kb` 与素材平台口径不完全对齐**：该技能描述为「美团/抖音扣点…」，而本店实际渠道为点评/美团/小红书（`08` §一）；抖音类目未在 `13` 中给出，若未来开抖音需另补费率。
3. **`SKILL.md` 正文「5–7%」仍为隐患**：建议改为「费率以签约费率素材/`platform-rules-kb` 为准，取不到即阻断（G1）」，并补上「叠加达人佣金」的措辞，避免下游误用（本单已识别并拒用）。
4. **计费基数是最易错点**：两项费用均按**核销金额**而非售价/下单金额（埋点 4）；本轮以 1 份核销为单位、取该套餐售价代入，并已标注「若核销额≠售价需重算」。
