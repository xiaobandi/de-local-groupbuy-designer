# 核销数据复盘调价 · 架构与流程图

## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：团购引流设计师 的使用者"]
  T["触发层：核销数据复盘调价"]
  X["执行层：3 个步骤"]
  O["产出层：调价/换品建议"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 所有做团购的到店门店；员工定位：把"被平台牵着走的低价团购"变成"算得清毛利的引流武器" |
| 触发层 | 关键词 / 显式点名「核销数据复盘调价」；触发方式：定时（每月） |
| 执行层 | 核销数据 → 识别滞销款 → 调价/换品建议 |
| 产出层 | 调价/换品建议 |
