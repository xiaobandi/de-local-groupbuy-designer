- **降级路径**：无费率取数通道 + `kb` 未入库 + 无脚本 → 手工推导，已在 ① 注明。
- **未完成步骤与原因**：5 步均走到；**「定价区间」这一最终结论为 `<待填>`**，原因是必需输入「费率」缺失，**非跳步、非编造**。
